# Higgsfield (optional, for generated visuals)

- Used for: the still (`nano_banana_2`, 16:9, 2k, ~2 credits) and video clips (`kling3_0`, 5 s,
  pro ~7.5 / std ~6.25 credits).
- Account and login: yours, through the official CLI. Install it
  (`brew install higgsfield-ai/tap/higgsfield`) and run `higgsfield auth login` in your terminal.
  `rlite` only ever reads your credit balance and plan, never your email.
- Resumable: `rlite` stores the job id before waiting and polls it on resume.
- Without Higgsfield, use `still` backgrounds from your own images (`byo`).
